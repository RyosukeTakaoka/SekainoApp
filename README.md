# ポテカウ 🍟

カメラで撮った(または選んだ)フライドポテトの写真から、本数を「それっぽく」判定するだけの、ニッチなネタWebアプリです。

- サーバー不要・アカウント不要。判定はすべてブラウザの中(JavaScript)で完結し、写真は外部に送信されません。
- 判定結果は称号(「ポテト見習い」〜「伝説のポテトフレンズ」)付きのシェアカード画像として書き出せます。
- 「𝕏 で結果をポストする」ボタンから、判定結果をそのままポスト文面としてシェアできます。

## 遊び方

1. `index.html` を開く(下記のローカル起動方法を参照)。
2. 「カメラを起動する」でポテトを撮影するか、「写真を選ぶ」で既存の写真を選択する。
3. 数秒後、本数と称号が書かれた結果カードが表示される。
4. 「画像を保存する」でカード画像をダウンロードし、Xアプリに添付して投稿するとシェアできる。
   (スマホの共有機能に対応している場合は「画像を共有する」ボタンから直接シェア可能)

## 判定の仕組み(概要)

1. 撮影・選択した画像をキャンバスに描画し、解析用に縮小。
2. 各ピクセルをHSV色空間に変換し、「ポテトらしい黄金色〜きつね色」の範囲だけを抽出してマスク画像を作成。
3. ノイズ除去(簡易モルフォロジー処理)をかけたのち、連結成分(かたまり)を検出。
4. 細長いかたまり(=ポテト1本らしき形状)の面積の中央値を「1本あたりの標準面積」とみなし、各かたまりの面積をその値で割って本数を推定・合算。

厳密な物体検出ではなく色と面積によるヒューリスティックなので、判定精度は保証しません(それがこのアプリの味です)。

## ローカルでの動作確認

ビルド不要の素のHTML/CSS/JavaScriptなので、静的ファイルを配信できれば何でも動きます。

```bash
# 例: Pythonの簡易サーバーを使う場合
python3 -m http.server 8080
```

ブラウザで `http://localhost:8080/` を開いてください。カメラ機能を使う場合、ブラウザによっては `localhost` 以外では HTTPS が必要になることがあります。

## デプロイ

静的ファイルのみなので、GitHub Pages・Vercel・Netlify・Cloudflare Pagesなど任意の静的ホスティングにそのまま公開できます。

## ファイル構成

```
index.html      画面構成(撮影 → 判定中 → 結果の3画面)
css/style.css   見た目(ポテトカラーのポップなデザイン)
js/app.js       カメラ制御・画像解析・結果カード描画・シェア機能
```
